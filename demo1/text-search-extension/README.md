# 文本搜索助手浏览器插件

一个智能的浏览器插件，让您在阅读网页时可以轻松搜索选中的文本，而不需要离开当前页面。

**🚀 版本 2.0.0 - 集成 HarmonyOS 算法优化，支持一次开发多端部署**

## 功能特点

- **自动搜索**: 在任意网页上用鼠标选中文本后，会自动弹出搜索窗口显示搜索结果
- **独立窗口**: 搜索结果在独立的小窗口中显示，不影响当前阅读内容
- **多搜索引擎**: 支持Google、百度、必应等搜索引擎切换
- **智能定位**: 搜索窗口会根据鼠标位置智能定位，避免遮挡重要内容
- **易于关闭**: 点击关闭按钮或页面其他区域即可关闭搜索窗口
- **HarmonyOS 算法优化**: 集成多项 HarmonyOS 核心算法，提升性能和用户体验
- **一次开发多端部署**: 支持浏览器扩展、HarmonyOS 应用、Web 应用等多平台

## HarmonyOS 算法说明

本插件集成了以下 HarmonyOS 核心算法：

### 1. 智能窗口定位算法 (Smart Position Algorithm)
**来源**: HarmonyOS 分布式 UI 布局算法

**功能**:
- 自适应边界检测和碰撞避免
- 根据设备类型自适应调整窗口位置
- 智能计算最佳显示位置
- 确保窗口始终在可视区域内

**优化点**:
- 移动端自动居中优化
- 平板设备边界适配
- 桌面端精确定位

### 2. 分布式缓存系统 (Distributed Cache)
**来源**: HarmonyOS 分布式数据管理框架

**功能**:
- LRU 缓存淘汰策略
- 支持 TTL 过期时间设置
- 自动淘汰最少使用的数据

**优化点**:
- 减少重复计算
- 提升响应速度
- 内存占用优化

### 3. 自适应调度器 (Adaptive Scheduler)
**来源**: HarmonyOS 资源调度框架

**功能**:
- 任务优先级调度
- 性能监控和指标记录
- 任务队列管理

**优化点**:
- 根据设备性能自动调整执行策略
- 避免界面卡顿
- 性能指标分析

### 4. 事件处理优化 (Event Optimization)
**来源**: HarmonyOS 事件处理机制

**功能**:
- 防抖 (Debounce) 优化
- 节流 (Throttle) 优化
- 自适应延迟调整

**优化点**:
- 根据设备类型自适应调整延迟时间
- 避免频繁触发导致的性能问题
- 优化用户交互体验

### 5. 设备检测与适配 (Device Detection)
**来源**: HarmonyOS 多设备适配框架

**功能**:
- 自动识别设备类型（移动端/平板/桌面）
- 检测设备性能参数
- 屏幕尺寸和 DPR 适配

**优化点**:
- 智能适配不同设备
- 性能参数自动优化
- 响应式布局支持

## 安装方法

### Chrome/Edge浏览器

1. 下载或克隆此项目到本地
2. 打开浏览器，访问 `chrome://extensions/` (Chrome) 或 `edge://extensions/` (Edge)
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹 `text-search-extension`
6. 插件安装完成！

## 使用说明

1. 在任意网页上浏览内容
2. 用鼠标选中您想要搜索的文本
3. 搜索窗口会自动弹出，显示搜索结果
4. 点击窗口右上角的 × 按钮或页面其他区域关闭窗口

## 配置选项

点击浏览器工具栏中的插件图标，可以打开设置页面：

- **搜索引擎**: 选择您偏好的搜索引擎（Google、百度、必应）
- **自动搜索**: 启用或禁用自动搜索功能

## 技术实现

### 核心技术
- **Manifest V3**: 使用最新的Chrome扩展API
- **Content Scripts**: 在页面中注入脚本监听选中文本事件
- **IFrame**: 使用iframe显示搜索结果，确保隔离性
- **Storage API**: 使用本地存储保存用户设置
- **响应式设计**: 搜索窗口会根据屏幕大小智能定位

### HarmonyOS 算法集成
- **harmonyos-algorithms.js**: 核心算法模块
- **智能定位**: 替代传统固定位置算法
- **性能优化**: 自适应设备性能
- **缓存机制**: 分布式缓存提升响应速度

### 多端适配架构
- **MultiPlatformAdapter**: 统一的多端适配器
- **设备检测**: 自动识别设备类型和性能
- **代码复用**: 核心算法跨平台共享
- **平台配置**: 每个平台独立的构建配置

## 注意事项

1. 由于浏览器的CORS策略，搜索结果通过iframe显示
2. 某些网站可能会阻止iframe嵌入，此时可以点击"在新标签页中打开"
3. 插件需要访问所有网站的权限才能正常工作
